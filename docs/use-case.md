# 代码统计系统用例

**Use case（用例）：** UC01 — 统计源代码。

**Primary Actor（主要参与者）：** 需要查看代码规模的用户，如学生或开发者。

**Goal in context（使用目标）：** 在浏览器本地统计源代码，了解有效代码行、空行、注释行及语言分布。

**Precondition（前置条件）：** 用户已打开网站，并准备好 C、C++、Python、Java、JavaScript 或 TypeScript 的 UTF-8 源文件或代码文本。

**Trigger（触发条件）：** 用户在工作台发起一次代码统计。

**Scenario（正常流程）：**

1. 用户选择统计档案。
2. 用户选择文件、文件夹，或粘贴代码并选择语言。
3. 用户点击“开始统计”。
4. 系统在浏览器本地读取和分析代码，不执行或上传源代码。
5. 系统显示统计结果、语言分布和文件明细，并保存扫描快照供之后查看。

**Exception（异常情况）：**

- 没有选择文件或输入代码时，不能开始统计。
- 文件不支持、无法读取或超出限制时，系统提示原因，并跳过或拒绝相应输入。
- 历史保存失败时，保留本次统计结果，并提示快照未保存。

**Frequency（使用频率）：** 按需使用；用户导入新代码或修改代码后，可再次发起统计。
