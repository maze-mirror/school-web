### 2026-11-04：导入可用性与 Python 类型声明

新增：

- 文件编码设置提供严格 UTF-8（默认）、“UTF-8 优先，失败按 GBK”和全部 GBK 三种读取策略。混合目录可显式选择 UTF-8 优先／GBK 回退；使用 GBK 的成功文件在明细及导出中标记，读取不会修改原文件。
- 编码转换说明：在编辑器中以原编码打开，核对中文后另存为 UTF-8，再选择 UTF-8 重试。
- `.pyi` 使用 Python 行分类，单列“Python 类型声明”，不并入 `.py/.pyw` 汇总，默认计入项目总量；接入汇总、语言分布、明细语言筛选、历史和 CSV／JSON／Excel 导出。不新增 `.pyi` 函数统计。

修复与调整：

- 排除目录、支持后缀筛选和相对路径去重提前到读取及限额计算之前；候选数量／字节数的预览、限额和实际读取使用同一集合，重复候选只计首份。
- 不支持的 `.so/.pyd/.pyz` 等直接跳过，不读取、不占限额，避免二进制文件误报需要转编码。读取失败、解码失败和含二进制空字符分别说明。
- 候选文件上限从 2000 调为 5000，以容纳 testcase3 纳入 `.pyi` 后的 3305 个候选源文件；保留单文件 5 MiB、候选总量 40 MiB 限制，以及超限时缩小范围／分次扫描提示。

兼容性：

- 行规则升为 `physical-lines-1.2`，编码策略写入扫描配置；旧历史不重算，不直接比较不同规则或配置的快照净变化。
- JSON 报表仍为 `schemaVersion: 2`，数据库结构不变；H001/H002 的暂缓事项保持不变。
